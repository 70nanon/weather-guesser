# Location Mode アップデート予定

ステータス: **計画のみ。このドキュメントでは実装しない。** 追記しながら育てる。

方針は Location Mode を **日本モード** と **世界モード** に分けること。

- 日本モード: 標準。天気比較で国内を絞れる難易度。
- 世界モード: 高難易度。今の世界規模出題を残す。

共通ルール（調査最大 3 回、気象項目、日の出・日の入り、地図タップで回答）は両モード同じ。違うのは正解リスト、地図の初期表示、距離スコアの減衰、説明文。

一括実装はしない。下のチケットは、前提が満たされていれば好きな順で進める。

---

## 現在の関連実装

Location Mode は `src/modes/LocationMode.tsx`、Forecast Mode は `src/modes/ForecastMode.tsx`。状態・採点・天気取得は分かれている。

### 正解地点

- `src/data/targetCities.ts` の `WORLD_CITIES`（46 都市）から `pickTargetCity(WORLD_CITIES)` で選ぶ。切替 UI（LM-8）までは世界のみ。
- 日本モード用の `JAPAN_CITIES`（47 都道府県庁所在地、id 2001–）は `src/data/japanCities.ts` にある。世界リストは残している。
- 地点名 / 国 / 座標はプレイヤーに出さない。天気取得失敗時は別候補を最大 3 回試す。
- `pickTargetCity(cities, excludeId)` は渡された配列から選ぶ。検索カタログは `searchCityCatalog()`（世界リスト + 日本リスト）。東京など両リストにある名前は検索結果で 1 件にまとめる。

### 天気表示

- `fetchWeatherSnapshot()` が現在気温・最高/最低・天気・湿度・降水量・風・気圧・日の出・日の入りを返す。
- `WeatherSnapshotCard` が描画。秘密地点では `place` を渡さない。調査結果では `札幌 / 日本` のように出す。
- 気象項目セットは両モードとも維持する。

### 調査

- 最大 3 回（`MAX_INVESTIGATIONS`）。両モード共通。
- `InvestigatePanel` で検索し、結果カードは `LocationMode` が縦に積む。
- 日本語検索は `searchLocalCities()` が `searchCityCatalog()`（世界リスト + 日本の県庁所在地）を先に照合し、なければ Open-Meteo geocoding。
- ローマ字エイリアスは都市名キーで検索側にあり、正解リストの id には依存しない。
- 調査地点は地図に出ていない。
- 調査の検索候補は左側が地点名、右側が「調査する」。`GeoLocation.country` はあるが候補行では出していない。Forecast の `LocationSearch` は国名を出している。
- 世界モードでも海外都市の調査が必要なので、検索カタログから世界都市を消してはいけない。

### 回答・採点

- `AnswerMap` は世界全体（`center=[20,10]`, `zoom=1`）。クリックで回答ピン（オレンジ）。
- 回答後だけ正解ピン（青）と破線。調査ピンはない。
- 距離は `haversineKm`、スコアは `locationScore`（最大 5000、`e^(-km/1500)`）。減衰 1500km は世界向け。調査回数ボーナスは 0。
- 日本モード用の減衰を足しても、世界モードは現行の 1500km を残す。

### Forecast との接点

- タブ以外は独立。
- `searchLocations()` / `searchLocalCities()` は共通。正解リストを日本だけにして世界リストを捨てると、予報の日本語世界都市検索が外れやすくなる。

## モード設計

| | 日本モード | 世界モード |
| --- | --- | --- |
| 位置づけ | 標準 | 高難易度 |
| 正解リスト | 国内の安定都市（県庁所在地中心） | 現行の世界 46 都市を維持・整理 |
| 地図の初期表示 | 日本全体 | 世界全体（現行に近い） |
| 距離スコア | 国内スケールの減衰 | 現行の減衰 1500km |
| 調査 | 最大 3 回。検索は国内も海外も可 | 同じ |
| 気象表示 | 現行セット | 同じ |
| 回答 | 地図タップ →「ここで回答」 | 同じ |

プレイヤーには、今どちらのスケールで遊んでいるかを明示する。同じ 5000 点満点でも、点の意味がモードで違う。

UI 案（実装時にどちらか）:

- 「予報 / 場所」はそのまま。場所の中に「日本 / 世界」を置く。おすすめ。
- 「予報 / 日本 / 世界」の 3 タブ。場所であることが薄れる。

デフォルトは日本モード。世界を選んだあとのラウンド途中で日本に切り替えるなら、進行中の問題は捨てて新しいラウンドを始める。

世界リストは消さない。日本化の過程で `TARGET_CITIES` を上書きしてしまうと、世界モードの復元が面倒になる。

## LM-1 調査候補を「地点名 / 国名」表示にする

## LM-3 正解リストと検索カタログを分離し、世界リストを残す

状態: **完了**（[PR #6](https://github.com/70nanon/weather-guesser/pull/6)）  
前提: なし。**LM-4 / LM-8 の前提。**

### やりたいこと

Location の正解配列と、両モード共通の検索カタログを別にする。今の世界 46 都市は **残す**。日本リストで上書きしない。

### 現状

`searchLocalCities()` が `TARGET_CITIES` を読んでいる。`ROMAJI_ALIASES` は世界都市の id に紐づいている。この配列が、今の実質的な世界モード用リスト。

### 方針

1. 世界正解リスト = 現行 `TARGET_CITIES` を `WORLD_CITIES` などへ改名して維持する。
2. 検索カタログ = 世界リスト + 日本の追加都市 + 将来の日本正解リスト。
3. `pickTargetCity()` は渡された配列だけを見る。このチケットでは Location の出題はまだ世界リストのまま。
4. aliases を検索側に寄せ、あとから日本リストを足しても世界検索が残るようにする。

実装: `TARGET_CITIES` を `WORLD_CITIES` に改名。`pickTargetCity` は配列必須。検索は `searchCityCatalog()` = 世界リスト + `SEARCH_ONLY_CITIES`。エイリアスは都市名キーの `SEARCH_ALIASES_BY_NAME`。出題はまだ世界のみ。

### 対象ファイル

- `src/data/targetCities.ts`（世界リストの名前と export）
- `src/data/searchCities.ts`
- それぞれのテスト

### 完了条件

- 世界 46 都市がコード上に残っている
- 東京・札幌・大阪と、ロンドン等の日本語検索が当たる
- Location の出題ロジックはまだ世界のみ

- `AnswerMap` に初期 center / zoom、または bounds を渡す。

## LM-7 距離スコアをモード別に分ける

前提: **LM-8**

### やりたいこと

距離スコアの考え方は維持（近いほど高得点、最大 5000、大円距離）しつつ、減衰をモードで分ける。世界モードに日本向け減衰を適用しない。

### 現状（世界向け、減衰 1500km）

- 50km ≈ 4836
- 500km ≈ 3585
- 1000km ≈ 2569
- 3000km ≈ 677

国内の距離感: 東京−大阪 約 400km、東京−札幌 / 福岡 約 800–900km、北海道−沖縄 約 2000km 超。

### 方針

式は現行と同じ `round(5000 * e^(-km / D))`。`D` をモードで変える。

| モード | D | 役割 |
| --- | --- | --- |
| 世界 | 1500（現行） | 高難易度。今の点の感覚を残す |
| 日本 | 600 または 800（実装時に調整） | 国内の地方差で点差がつく |

日本モード・D=800 の目安:

| 距離 | 点 | 感覚 |
| --- | --- | --- |
| 50km | 約 4700 | ほぼ満点 |
| 200km | 約 3900 | 高得点 |
| 400km | 約 3000 | 東京−大阪級 |
| 800km | 約 1800 | 東京−札幌級 |
| 1500km | 約 770 | 低い |
| 2000km+ | 約 400 以下 | ほぼ外れ |

最大 5000、調査回数ボーナス 0 は両モード共通。
`locationScore(distanceKm, investigationsUsed, region)` のように引数を足すか、減衰定数を外から渡す。

### 対象ファイル

- `src/logic/locationScore.ts`
- `src/logic/locationScore.test.ts`
- `src/modes/LocationMode.tsx`（呼び分け）

### 完了条件

- 日本モードで国内スケールの点差がつく
- 世界モードの点が現行とほぼ同じ
- Forecast の 100 点スコアは触らない
